OFFLINE EVENT CHECKPOINT SYSTEM

免費的定向越野，
從這裡開始。

ScanPoint 是為現場活動打造的離線刷卡系統。掃描站獨立記錄、 多份即時備份，活動結束後也能輕鬆計分。

認識 ScanPoint → 開始建立站點 進行成績計算

ONE SETUP, ONE CHECKPOINT

一台 Windows 電腦，一台 NFC 讀卡機， 就是一個站點。

每個站點會獨立記錄參加者的 NFC 手環刷卡時間並保存資料，不需要持續連線。活動結束後匯入各站紀錄，就能計算完成時間與排名。

BUILT FOR THE FIELD

現場越忙，系統越要簡單可靠。

從讀卡到備份都以無人值守的掃描站為核心設計， 操作員只需要確認畫面與提示音。

01
⌁

快速掃描與防重複

支援鍵盤模擬式讀卡機，即時辨識有效、重複與不完整封包，中文輸入法也不干擾刷卡。

  • Enter 與讀卡機結尾碼
  • 畫面、聲音雙重回饋
02
≋

資料不只留一份

每次刷卡同步寫入 EXE 同層主記錄與 AppData 常駐紀錄，還能額外備份到隨身碟。

  • JSONL 與 CSV 格式
  • 拔除隨身碟不影響主紀錄
03
↥

活動後集中處理

管理介面可以查看掃描與操作歷史、匯出完整快照，再手動一次上傳到雲端。

  • 離線優先，不依賴即時網路
  • 穩定 ID 避免重複上傳
