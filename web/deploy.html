貼上雲端接收程式

把完整雲端接收程式貼到試算表的 Apps Script

請先完成第 2 步。選擇設定方式後，這裡會告訴你要貼哪一份程式， 以及是否需要另外新增指令碼屬性。

1

回到你在第 2 步貼上連結的空白試算表，從上方選單點「擴充功能 → Apps Script」。

2

Apps Script 會在新分頁開啟。點左側現有的程式碼檔，按 Ctrl + A 刪除原本內容。檔名可能顯示為 Code.gs、程式碼.gs、程式碼.js 或其他名稱，名稱不影響功能。

3

按下方「複製完整程式碼」，回到剛才的編輯器貼上全部內容，再按 Ctrl + S 儲存。

4

開啟左側「專案設定 → 指令碼屬性」，按照第 2 步的清單新增三組名稱和值。

請先完成第 2 步。
預覽將貼入 Apps Script 的完整程式碼 ⌄ 
完成第 2 步後顯示程式碼。

取得連線網址

把 Apps Script 部署成網頁應用程式

完整程式碼儲存完成後，在 Apps Script 右上角建立正式部署。 請按照下方順序選擇；不要使用「測試部署」，因為掃描站需要固定的正式網址。

    部署右上角按鈕
  2. 2
    新增部署作業不是測試部署
  3. 3
    選取類型按齒輪圖示
  4. 4
    網頁應用程式Web app
類型 網頁應用程式 不要選 API 執行檔或程式庫
執行身分 我 使用你的帳號寫入試算表
說明 ScanPoint 雲端上傳 說明只是方便辨識，可直接照這段文字填寫
誰可以存取 任何人 掃描站不會登入 Google，不能選「僅限自己」
1

按「部署」，第一次會要求授權。選擇你建立這份試算表與 Apps Script 的 Google 帳號。

2

若出現「Google 尚未驗證這個應用程式」，只在這是你自己建立、並親自貼入上述程式碼的專案時，點「進階」→「前往專案名稱（不安全）」→「允許」。不要對陌生人提供的 Apps Script 這樣操作。

3

完成後複製「網頁應用程式網址」，正式網址必須以 /exec 結尾。

4

先在瀏覽器開啟網址；看到 "ok": true 代表服務已啟動，再把網址貼到下方。

正式網址格式 https://script.google.com/macros/s/你的部署ID/exec

日後修改 Apps Script 程式碼：使用「部署 → 管理部署作業 → 編輯 → 新版本」， 原本的 /exec 網址就能繼續使用。

05↓

產生可直接設定的 Windows 軟體

下載已含雲端配置的完整最新版

網頁會取得 GitHub 上最新建置完成的 ScanPoint Windows 軟體，並只在你的瀏覽器中加入預設的 station.json 與已設定完成的 cloud.config。後者包含試算表 ID、正式網址與上傳金鑰，內容不會上傳到 GitHub。 第一次啟動軟體時，畫面會要求你設定這台電腦的站點編號與名稱。

06

解壓縮後即可使用

解壓縮並完成這台電腦的站點設定

  1. 把下載的 ZIP 解壓縮到這台 Windows 電腦，不要直接在壓縮檔內執行。
  2. 資料夾內會有 scan_point.exe、station.json 與 cloud.config；請保持三者在同一層。
  3. 第一次執行 scan_point.exe 時，依畫面要求設定這台電腦的站點編號與名稱；不同掃描站請使用不同編號。
  4. scanpoint-keys.json 是管理與成績計算用的完整金鑰備份，請另外放在安全位置，不必放進掃描站資料夾。
