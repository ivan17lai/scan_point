SPREADSHEET_ID 尚未輸入
UPLOAD_KEY
READ_KEY

到 Apps Script 左側「專案設定 → 指令碼屬性」，新增上面三個名稱和值。 UPLOAD_KEY 會自動帶入下一步的站點設定； READ_KEY 則用於成績計算頁讀取資料，兩者請勿設成相同值。

Web app deployment

部署成網頁應用程式

Apps Script 右上角的「部署」會出現多個選項。這裡要建立正式上傳網址， 請選「新增部署作業」，不要使用測試部署。

  1. 1
    部署右上角按鈕
  2. 2
    新增部署作業不是測試部署
  3. 3
    選取類型按齒輪圖示
  4. 4
    網頁應用程式Web app
類型 網頁應用程式 不要選 API 執行檔或程式庫
執行身分 我 使用你的帳號寫入試算表
誰可以存取 任何人 掃描站不會登入 Google，不能選「僅限自己」
1

按「部署」，第一次會要求授權；選擇你的 Google 帳號並允許試算表存取。

2

完成後複製「網頁應用程式網址」，正式網址必須以 /exec 結尾。

3

先在瀏覽器開啟網址；看到 "ok": true 代表服務已啟動。

4

把同一個網址貼到下一步的「Apps Script 部署網址」。

正確網址格式 https://script.google.com/macros/s/你的部署ID/exec

日後修改 Code.gs：使用「部署 → 管理部署作業 → 編輯 → 新版本」， 原本的 /exec 網址就能繼續使用。
