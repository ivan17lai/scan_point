產生可直接設定的 Windows 軟體

下載已含雲端配置的完整最新版

網頁會取得 GitHub 上最新建置完成的 ScanPoint Windows 軟體，並只在你的瀏覽器中加入預設的 station.json 與已設定完成的 cloud.config。後者包含試算表 ID、正式網址與上傳金鑰，內容不會上傳到 GitHub。 第一次啟動軟體時，畫面會要求你設定這台電腦的站點編號、名稱與管理 PIN。

直接下載最新的 ScanPoint Windows 軟體，不加入 cloud.config、試算表 ID 或任何金鑰。 第一次啟動時只需要設定站點編號、名稱與管理 PIN，之後所有掃描資料都保存在本機並可手動匯出。

重要：這是必要檔案，完成部署後請務必下載並安全保存。
鑰匙檔包含 Apps Script 正式網址、試算表 ID 與讀寫金鑰。不要放進掃描站資料夾， 也不要公開分享；成績計算時只需匯入這一個檔案。

05

解壓縮後即可使用

解壓縮並完成這台電腦的站點設定

  1. 把下載的 ZIP 解壓縮到這台 Windows 電腦，不要直接在壓縮檔內執行。
  2. 資料夾內會有 scan_point.exe、station.json 與 cloud.config；請保持三者在同一層。
  3. 離線版不包含 cloud.config 或任何金鑰；解壓縮後直接執行 scan_point.exe。
  4. 第一次執行 scan_point.exe 時，依畫面要求設定這台電腦的站點編號、名稱與管理 PIN；不同掃描站請使用不同編號。
  5. scanpoint-keys.json 是管理與成績計算用的完整金鑰備份，請另外放在安全位置，不必放進掃描站資料夾。
  6. 需要集中統計時，從掃描站設定介面匯出紀錄，再帶到計分電腦處理。
